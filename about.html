About Our Project

This website is developed as part of our academic project. It is a multi-page personal profile website that showcases our team, skills, and projects in a clean and modern design.

Our goal is to create a user-friendly and interactive website using HTML, CSS, and JavaScript. This project helps us understand the fundamentals of web development and design.
